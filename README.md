# 案例项目

这里放的是可以直接拿来练习 Codex 的小项目。每个项目都有自己的 `README.md`，里面包含练习目标、建议提示词和验收标准。

## 项目列表

1. `personal-homepage`：个人主页练习项目
2. `todo-lite`：待办清单练习项目
3. `expense-calculator`：费用计算器练习项目

## 推荐使用方式

每次只打开一个案例项目，按下面顺序练习：

1. 让 Codex 阅读项目结构。
2. 让 Codex 解释功能入口。
3. 选择一个练习任务。
4. 让 Codex 先给修改计划。
5. 确认后再修改。
6. 修改后让 Codex 总结改动和验证方式。

## 通用提示词

```text
请阅读这个案例项目，告诉我项目结构、主要文件和功能入口。先不要修改文件。
```

```text
请根据 README 里的练习任务，选择一个适合初学者的任务，先给出修改计划。
```

```text
请实现这个任务，保持改动尽量小。完成后说明我应该如何验收。
```
