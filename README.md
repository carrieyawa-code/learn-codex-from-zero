# 从0到1学习 Codex

这个项目用来系统学习 Codex：从会提问、会让它读项目，到能让它协助改代码、补测试、做代码审查和整理工作流。

## 学习目标

- 把 Codex 当作代码协作者，而不是简单问答工具。
- 学会给 Codex 清晰的目标、上下文、限制和验收标准。
- 掌握读代码、改代码、调试、测试、审查和自动化这些核心场景。
- 建立自己的提示词库和练习记录。

## 推荐学习顺序

1. 阅读 `01-认识Codex.md`
2. 阅读 `02-读代码.md`
3. 阅读 `03-改代码.md`
4. 阅读 `04-调试与测试.md`
5. 阅读 `05-代码审查.md`
6. 阅读 `06-自动化工作流.md`
7. 完成 `exercises/第1周练习.md`
8. 持续补充 `prompts/常用提示词.md`

## 你和 Codex 的分工

你负责：

- 明确目标
- 提供业务背景
- 判断方案是否符合真实需求
- 做最终验收

Codex 负责：

- 阅读和解释代码
- 定位问题和相关文件
- 给出修改方案
- 执行代码修改
- 运行验证并解释结果

## 学习建议

不要一开始就追求“完美提示词”。更好的方式是从真实小任务开始，一步一步练习：

- 先让 Codex 解释项目。
- 再让它定位某个功能。
- 然后让它做一个很小的修改。
- 最后让它验证结果并总结改动。

你会在这个过程中自然建立自己的使用习惯。
